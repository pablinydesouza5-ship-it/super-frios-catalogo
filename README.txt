SUPER FRIOS — CATÁLOGO DIGITAL

Projeto estático pronto para publicação na Vercel.

ARQUIVOS
- index.html: estrutura e conteúdo do site
- styles.css: identidade visual e layout responsivo
- assets/: imagens extraídas das 10 páginas do PDF original

COMO PUBLICAR
1. Extraia o ZIP em uma pasta no computador.
2. Entre em https://github.com e crie um repositório novo (por exemplo: super-frios-catalogo).
3. Envie todos os arquivos e a pasta assets para esse repositório, mantendo a estrutura.
4. Entre em https://vercel.com, escolha Add New > Project e importe o repositório do GitHub.
5. Para este projeto, não é necessário configurar build command nem output directory. Clique em Deploy.
